# Ozon 选品自动化插件 — 开发任务拆分

> 基于「自动化流程.docx」需求文档 · 2026-04-29

---

## 整体架构概览

```
┌─────────────┐    ┌──────────────┐    ┌──────────────┐
│  数据获取层  │ → │  计算分析层   │ → │  展示交互层   │
│ (爬取+API)  │    │ (定价+利润)   │    │ (表格+人工筛) │
└─────────────┘    └──────────────┘    └──────────────┘
       ↑                                      ↓
       └──────── 配置 & 存储层 ←──────────────┘
```

**技术方案建议**：Chrome 扩展（popup.html + content script + background service worker）

## 模块一：数据源接入模块（Seerfar 数据获取）

### 1.1 Seerfar 热销榜单抓取
- **输入**：Seerfar 筛选条件（评分≥4.5，评论≥100，订单≥200）
- **逻辑**：通过 API 或页面爬取 Seerfar 热销榜/最新上架/类目榜单/热销店铺
- **输出**：原始商品列表（含商品ID、名称、链接等基础信息）

### 1.2 Seerfar 类目数据抓取
- **输入**：用户选择的类目ID(难点，有反扒机制 无法，通过api实现)
- **逻辑**：按类目树递归/分页获取类目下所有商品
- **输出**：类目商品列表

### 1.3 Seerfar 店铺数据抓取(不确定是否跟类目数据一直)
- **输入**：店铺评分、评论数等筛选条件
- **逻辑**：爬取评分 4.5+ 的热销店铺，再获取店铺内商品
- **输出**：店铺商品列表

### 1.4 筛选条件引擎
- **输入**：原始商品列表 + 用户手动设置的筛选条件
- **筛选条件**：
  - ① 跟卖数范围
  - ② 月销量区间（最小~最大）
  - ③ 商品售价区间（最低价~最高价）
  - ④ 发货模式 = FBS
  - ⑤ 商品创建天数范围
  - ⑥ 商品重量范围
- **逻辑**：逐条件过滤，支持 AND 组合
- **输出**：初步筛选后的商品列表

## 模块二：价格获取模块（绿标最低价 + 商品详情）

### 2.1 Ozon 绿标最低价链接获取
- **输入**：筛选后的商品列表
- **依赖**：需要对接俄罗斯 ERP 系统（获取绿标/黑标价格）
- **逻辑**：
  - 调用 ERP API 获取每个商品的绿标价格（最低价链接）
  - 同时获取黑标价格（用于后续定价计算）
- **输出**：每个商品的 {绿标价格, 黑标价格, 最低价链接}

### 2.2 Ozon 商品详情爬取
- **输入**：商品链接列表
- **爬取内容**：
  - 重量（克）
  - 尺寸（长×宽×高 cm）
  - 类目佣金（平台上有显示）
  - 运费（按地区/重量计算）
- **逻辑**：逐个访问 Ozon 商品详情页，提取关键字段
- **输出**：每个商品的详情 JSON

### 2.3 5% 杂费计算
- **输入**：推荐售价
- **逻辑**：杂费 = 推荐售价 × 5%
- **输出**：杂费金额
- **注意**：此值依赖售价，需在定价计算后回传

## 模块三：定价计算模块

### 3.1 推荐售价计算
- **输入**：绿标价格、黑标价格
- **公式**：`推荐售价 = (黑标 - 绿标) × 2.2 + 黑标 - 1`
- **输出**：推荐售价（卢布）

### 3.2 1688 / 拼多多 比价接口对接
- **输入**：商品名称 / 图片搜索
- **逻辑**：
  - 调用 1688 API（或爬取）搜索同款商品
  - 调用拼多多 API（或爬取）搜索同款商品
  - 取两个平台的最低采购价
- **输出**：最低采购成本（人民币）、采购链接

### 3.3 利润 & 利润率计算
- **输入**：推荐售价、杂费、佣金、运费、采购成本
- **公式**：
  ```
  利润 = 推荐售价 - 5%杂费 - 佣金 - 运费 - 采购成本 × 汇率
  利润率 = 利润 / 推荐售价 × 100%
  ```
- **输出**：利润（卢布）、利润率（百分比）

### 3.4 利润筛选
- **逻辑**：过滤利润率 ≥ 22%（或用户自定义阈值）
- **输出**：最终符合条件的商品列表

## 模块四：结果展示模块（表格 + 人工筛选 UI）

### 4.1 结果表格生成
表格列（10项）：

| 序号 | 字段 | 来源 |
|------|------|------|
| ① | **商品主图** | Ozon 页面爬取 |
| ② | **Ozon 链接 / 1688/PDD 链接** | 模块二+三 |
| ③ | **Ozon 推荐售价** | 模块三计算 |
| ④ | **商品尺寸** | 模块二爬取 |
| ⑤ | **商品重量** | 模块二爬取 |
| ⑥ | **佣金** | 模块二爬取 |
| ⑦ | **月销量** | 模块一获取 |
| ⑧ | **跟卖数量** | 模块一获取 |
| ⑨ | **利润** | 模块三计算 |
| ⑩ | **利润率** | 模块三计算 |

### 4.2 商品主图展示
- 表格中嵌入缩略图
- 点击可放大查看
- 类似 "乌拉" 插件的卡片式展示

### 4.3 人工筛选功能
- ☑️ 每行可勾选/取消
- 🎯 支持批量勾选
- 🔍 支持按利润率/销量/利润排序
- 📊 顶部显示统计（总利润、平均利润率等）

### 4.4 一键上架
- **输入**：用户勾选的商品列表
- **逻辑**：
  - 调用 Ozon Seller API 创建商品
  - 自动填充推荐售价、库存等信息
  - 上传主图
- **输出**：上架成功/失败反馈
- **注意**：可能需要对接现有 ERP 的上架接口

## 模块五：配置 & 存储模块

### 5.1 用户配置管理
- Seerfar API 密钥 / Cookie
- Ozon ERP API 密钥
- 1688 / PDD 账号 Cookie
- 利润率阈值（默认 22%）
- 汇率设置
- 默认筛选条件预设

### 5.2 数据持久化
- 筛选结果本地缓存（localStorage / IndexedDB）
- 人工筛选进度保存
- 上架记录日志

### 5.3 错误处理 & 重试
- API 限流处理
- 爬取失败重试（最多 3 次）
- 部分成功/部分失败的场景处理

## 模块六：UI/UX 设计

### 6.1 Popup 主界面
- 筛选条件配置面板（折叠/展开）
- 数据源选择（榜单/类目/店铺）
- "开始筛选"按钮 + 进度条

### 6.2 结果展示页（独立 Tab/窗口）
- 参考 "乌拉" 拉插设计：
  - 卡片式/表格式混合布局
  - 商品主图突出显示
  - 关键指标（利润、利润率）高亮
  - 拖拽排序

### 6.3 定价模板集成
- 接口对接现有的"网页版定价模板"
- 在结果展示页中嵌入定价详情

## 开发优先级 & 里程碑

| 阶段 | 模块 | 预估工作量 | 产出 |
|------|------|-----------|------|
| **P0 MVP** | 模块一（Seerfar 筛选）+ 模块四（表格展示） | 3-5天 | 能筛选+看结果 |
| **P1 核心** | 模块二（Ozon 价格爬取）+ 模块三（定价+利润） | 5-7天 | 有利润数据 |
| **P2 进阶** | 模块三（1688/PDD 比价）+ 模块四（人工筛选 UI） | 3-5天 | 可人工筛+上架 |
| **P3 完善** | 模块五（配置存储）+ 模块六（UI 优化） | 2-3天 | 可复用+好用 |

## 关键技术风险

| 风险 | 影响 | 缓解方案 |
|------|------|---------|
| 毛子 ERP 接口不明确 | 绿标/黑标价格获取受阻 | 先和 ERP 供应商确认 API 文档 |
| Seerfar 反爬 | 数据源不可用 | 准备 Cookie 注入 + 频率控制 |
| 1688/PDD 反爬严重 | 比价功能不可用 | 用官方 API 或第三方数据接口 |
| Ozon Seller API 权限 | 上架功能受限 | 提前注册 Ozon API 权限 |
