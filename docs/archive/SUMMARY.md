## 🔧 技术架构

### 分层设计

```
┌─────────────────────────────────────┐
│         UI Layer (popup-new)        │  用户界面
├─────────────────────────────────────┤
│      Controller (main-controller)   │  业务流程
├─────────────────────────────────────┤
│  Services (product-data, match1688) │  核心服务
├─────────────────────────────────────┤
│    Content Scripts (seller-bridge)  │  API 桥接
├─────────────────────────────────────┤
│         Ozon API / 1688 API         │  数据源
└─────────────────────────────────────┘
```

### 核心模块

#### 1. ProductDataService
**职责**: 商品数据的获取、转换、筛选、计算

**核心方法**:
- `fetchFromSellerAPI()` - 从 Seller API 获取数据
- `fetchProductDetails()` - 从前台 API 获取详情
- `normalizeFromSellerAPI()` - 数据标准化
- `mergeProductDetails()` - 合并详细信息
- `applyFilters()` - 应用筛选规则
- `calculatePricing()` - 计算定价和利润

#### 2. Match1688Service
**职责**: 1688 同款匹配和采购价比对

**核心方法**:
- `searchByImage()` - 以图搜图
- `batchMatch()` - 批量匹配
- `_downloadImageAsBase64()` - 图片处理
- `_normalize1688Item()` - 数据标准化

#### 3. MainController
**职责**: 整合所有服务，提供统一的业务流程接口

**核心方法**:
- `executeFullPipeline()` - 执行完整流程
- `exportToExcel()` - 导出 Excel
- `exportToHTML()` - 导出 HTML 报告

## 💡 核心算法

### 1. 推荐售价计算
```javascript
推荐售价 = (黑标价格 - 绿标价格) × 2.2 + 黑标价格 - 1
```

### 2. 利润计算
```javascript
杂费 = 推荐售价 × 5%
佣金 = 推荐售价 × 佣金率（默认 15%）
运费 = 按重量分段计算
利润 = 推荐售价 - 杂费 - 佣金 - 运费 - 采购成本
```

### 3. 利润率计算
```javascript
利润率 = (利润 / 推荐售价) × 100%
筛选条件: 利润率 ≥ 22%
```

### 4. 运费计算
```javascript
≤1kg:  150₽
≤5kg:  250₽
≤10kg: 400₽
≤20kg: 600₽
>20kg: 600₽ + (重量-20) × 30₽
```
